# مودة (Mawadda) — بطاقات حوارية إسلامية هادفة للتعارف قبل الزواج

تطبيق محمول متكامل مبني بتقنية Flutter (مع نسخة تفاعلية فورية عبر الويب) مخصص للمقبلين على الزواج في العالم الإسلامي، لفتح آفاق الحوار الجاد والعميق حول القيم، والمسؤوليات، وطريقة التفكير، وإدارة الأسرة والمال والمستقبل، في إطار من الوقار والحياء والأخلاق الإسلامية الرفيعة.

---

## 🌟 الرؤية والمنطلقات

- **ليس تطبيق مواعدة أو تعارف عشوائي:** لا توجد ملفات شخصية عامة، ولا محادثات بين غرباء، ولا خوارزميات توافق قائمة على الأبراج أو التخمين.
- **حوار أسري محترم:** صُمم التطبيق ليكون رفيق الجلسات الحوارية الجادة في حضور العائلة والأهل.
- **خصوصية 100% دون إنترنت (Offline):** لا يتطلب تسجيلاً أو اتصالا بالإنترنت أو أذونات وصول مشبوهة، ولا يجمع أي بيانات خاصة.
- **تدرج ذكي (3 مستويات):** من التعارف الأولي الودي إلى الفهم الأعمق للمبادئ، وصولاً إلى مناقشة المواقف والسيناريوهات والقرارات الحياتية المشتركة.

---

## 📚 محاور الأسئلة (180 سؤالاً أصيلاً وموثقاً)

يحتوي التطبيق على **180 سؤالاً عربياً فصيحاً ومدروساً** مقسمة بالتساوي (30 سؤالاً لكل محور، بواقع 10 أسئلة لكل مستوى) عبر 6 محاور رئيسية:

1. **الدين والقيم:** المبادئ الروحية، الالتزام بالفرائض والسنن، أسلوب التواصي بالحق، والتعامل مع الخلافات الفقهية ومظاهر التدين.
2. **الشخصية وطريقة التفكير:** إدارة الغضب، التعبير عن المشاعر، النقد البناء، عادات النوم والاسترخاء، واتخاذ القرارات تحت الضغط.
3. **الأسرة والعلاقات:** بر الوالدين، صلة الرحم، حدود خصوصية البيت الزوجي، والتعامل الحكيم مع تدخلات الأهل وسوء التفاهم.
4. **المسؤوليات والحياة الزوجية:** الشراكة المنزلية، إدارة شؤون البيت اليومية اقتداءً بالنبي ﷺ في مهنة أهله، وتوزيع الأدوار بمرونة.
5. **المال والعمل والطموح:** النفقة الشرعية، الذمة المالية المستقلة، ثقافة الادخار والاستثمار، ودعم الطموح المهني دون الإخلال بالأسرة.
6. **الأبناء والمستقبل:** توقيت الإنجاب، أساليب التربية الإسلامية الإيجابية، الحماية الفكرية والرقمية، وبناء الأجيال الصالحة.

## 🚀 تشغيل وتطوير تطبيق Flutter

### المتطلبات الأساسية
- Flutter SDK (الإصدار 3.16 فما فوق)
- Dart SDK (الإصدار 3.2 فما فوق)
- Android Studio أو VS Code مع حزمة إضافات Flutter

### خطوات التشغيل المحلي
```bash
# 1. استنساخ المشروع وتثبيت الحزم
flutter pub get

# 2. فحص وتنسيق الكود
dart format .
flutter analyze

# 3. تشغيل الاختبارات المؤتمتة
flutter test

# 4. تشغيل التطبيق على الهاتف أو المحاكي
flutter run
```
